# বাংলা টেসলা · Bangla Tesla (SpaceX Thruster & GTA Mama Edition)

A 3D WebGL browser game built with Three.js featuring a SpaceX cold-gas thruster-equipped Bangladeshi Auto-Rickshaw ("Bangla Tesla"), GTA-style on-foot Rickshawala Mama melee combat (60s timer & 35m tether radius), full Xbox/PlayStation Gamepad support with dual-rumble haptic vibration, and responsive mobile landscape touch controls.
